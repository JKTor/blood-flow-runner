# AR Blood Flow Runner — แข่งรถเม็ดเลือดในหัวใจ

เกม AR สอนระบบหมุนเวียนเลือด ม.1–2 เปิดบนไอแพด → กล้องหน้าถ่ายนักเรียน → หัวใจ 3D ลอยบนภาพกล้อง → นักเรียนเล่นด้วยการชูมือ

**เล่นได้ที่:** https://jktor.github.io/blood-flow-runner/ (เปิดด้วย Safari บนไอแพด แล้วกด "อนุญาต" ให้ใช้กล้อง)

## วิธีเล่น
- ทีมเลือดดำนั่ง **ฝั่งซ้ายของจอ** (วิ่งหัวใจซีกขวา: ร่างกาย → ปอด) · ทีมเลือดแดงนั่ง **ฝั่งขวาของจอ** (วิ่งหัวใจซีกซ้าย: ปอด → ร่างกาย)
1. คำถามขึ้นจอ → ทีมที่รู้ **ชูมือแบ 🖐 ค้างไว้** ในโซนตัวเอง หลอดเต็มก่อนได้ตอบ
2. ตอบด้วยการ **ชูนิ้ว 1 / 2 / 3 ค้างไว้** — ผิด อีกทีมแย่งตอบได้
3. ตอบถูก → เลือก **การ์ดคำสั่ง** (ชูนิ้วเหมือนเดิม) ถูก = รถวิ่งไปด่านต่อไป · ผิด = รถชนผนัง เสียตา
4. ทีมแรกที่วิ่งครบ 4 ด่านชนะ → โชว์เลือดไหลครบวงจร

ถ้ากล้องจับมือไม่ติด **แตะปุ่มบนจอแทนได้ทุกขั้น** · ปุ่ม ⚙︎ เมนูครู = ข้ามคำถาม / เริ่มใหม่ / สลับกล้อง / ปิดเสียง

## ทิปส์ตอนพรีเซนต์
- ตั้งไอแพดแนวนอน ยืนห่างกล้อง 1–2 เมตร ห้องสว่างพอ ชูมือให้เห็นทั้งฝ่ามือ
- วงกลมตัวเลขเหนือมือบนจอ = เครื่องอ่านได้กี่นิ้ว ถ้าตรงแล้วค้างไว้ ~1 วินาที
- อยากฉายขึ้นจอใหญ่: AirPlay / สาย HDMI จากไอแพด
- เพิ่มหน้าเว็บลงหน้าจอโฮม (ปุ่มแชร์ → "เพิ่มไปยังหน้าจอโฮม") จะได้เต็มจอเหมือนแอป

## แก้คำถาม
เปิด `questions.js` แก้/เพิ่มได้เลย (ตัวเลือกต้องมี 3 ข้อ, `answer` = เลขข้อที่ถูก เริ่มนับ 0)

## ไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` / `style.css` | หน้าตาเกม |
| `game.js` | ตัวเกม: ฉาก 3D, จับมือ, กติกา, เสียง |
| `questions.js` | คลังคำถาม 30 ข้อ |
| `vendor/` | Three.js + MediaPipe Hand Landmarker (เก็บไว้ในเครื่อง ไม่ต้องพึ่งเน็ตตอนเล่น ยกเว้นฟอนต์) |

ทดสอบในคอม: `python -m http.server 8760` แล้วเปิด http://localhost:8760
